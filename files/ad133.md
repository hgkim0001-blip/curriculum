# 애프터 이펙트 템플릿 리스트 (입문자 강의용)

2026-09-30 · 김사부

## 개요

본편집 단계에서 입문자가 바로 쓸 수 있는 애프터 이펙트 템플릿을 자막 계열부터 표준화한다. 학생은 텍스트·색상·로고 등 몇 가지 값만 바꿔 결과물을 내고, Claude + MCP로 템플릿을 만드는 과정도 함께 배운다.

- 수업 흐름: 가편집(시퀀스 개념) → 본편집(애프터 이펙트: 합성, 자막, 타이틀, 로고)
- 대상: 완전 입문자
- 방식: 에센셜 그래픽스 패널로 바꿀 값만 노출하고, 키프레임·이펙트 설정은 감춘다

## 입문자용 핵심 템플릿

4개 계열 14종이 핵심이며, 활용도가 가장 높은 자막 계열부터 만든다.

| 계열 | 템플릿 | 용도 | 학생이 바꿀 값 |
|---|---|---|---|
| 자막 | 대사 자막 | 화면 하단 기본 대사 | 텍스트 |
| 자막 | 인터뷰 자막 | 인터뷰 발언 표시 | 텍스트 |
| 자막 | 로워 서드 | 인터뷰이 이름·직함 표시 | 이름, 직함, 색상 |
| 자막 | 키워드 강조 자막 | 핵심 단어를 크게 강조 | 텍스트, 색상 |
| 자막 | 로케이션 자막 | 장소·시간 표시 (예: 수원시청 앞) | 장소, 날짜 |
| 자막 | 감정 표현 자막 | 예능·유튜브식 튀어나오는 글자 | 텍스트, 색상 |
| 타이틀 | 오프닝 타이틀 | 영상 시작 제목 | 제목, 색상 |
| 타이틀 | 서브 타이틀 | 부제 표시 | 텍스트 |
| 타이틀 | 챕터·소제목 타이틀 | 구간 구분 | 텍스트, 번호 |
| 로고·브랜딩 | 로고 인트로 | 영상 시작 로고 애니메이션 | 로고 이미지 |
| 로고·브랜딩 | 로고 아웃트로 | 영상 끝 로고 애니메이션 | 로고 이미지 |
| 로고·브랜딩 | 워터마크 로고 | 화면 구석 상시 로고 | 로고 이미지, 위치 |
| 마무리 | 엔드 카드 | 영상 마지막 화면 | 텍스트, 이미지 |
| 마무리 | 콜 투 액션 | 구독·좋아요 유도 | 텍스트, 색상 |

## 추가 활용 템플릿

핵심 템플릿 이후 수업 진도에 맞춰 추가할 수 있는 후보들이다.

| 템플릿 | 용도 |
|---|---|
| 색보정 프리셋 | 영상 톤을 한 번에 통일 |
| 오디오 세팅 | 배경음악·효과음 기본 구성 |
| 카운트다운·타이머 | 인트로용 그래픽 |
| 비율별 프레임 | 세로(9:16), 정사각형(1:1), 가로(16:9) SNS 규격 |
| 차트·그래프 애니메이션 | 데이터 시각화 (저널리스트 과정에 적합) |
| 전환 마스크·도형 애니메이션 | 장면 전환 |
| 타이핑 효과 | 글자가 타이핑되듯 나타나는 텍스트 |

## 중급 이상 확장 계획

실제 작업물을 열어 하나씩 논의하며 진행한다.

- **기존 작업물 템플릿화**: 디펜던시로 정리된 2D·3D 모션 그래픽, 3D 카메라 레이어 작업물을 MCP로 분석해 변수(텍스트, 카메라, 라이팅, 블렌딩, 파티클 등)를 열어준다. 종류별 샘플 하나로 표준 방식을 먼저 정한다.
- **톤 앤 매너 분석**: 레퍼런스 영상의 색감, 폰트, 전환 리듬, 모션 속도를 분석해 자체 스타일 템플릿으로 재해석한다. "이 영상은 왜 이런 느낌일까"를 분석하는 수업 주제로도 활용한다.
