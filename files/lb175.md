## 1. 핵심 요약 (이 7가지가 이 스타일을 만든다)

| # | 원칙 | 수치 |
|---|---|---|
| 1 | **24fps 위에 "투스(on twos)" 애니메이션**: 변화가 정확히 2프레임마다 한 번(=12fps). 짝수 프레임 변화량 10~30, 홀수 프레임 0.1~0.5 | 스텝 12fps |
| 2 | **정지 구간이 거의 없다**: 문구가 다 나온 뒤에도 배경 선버스트가 계속 돌고, 별이 반짝이고, 색이 흐른다. 프레임 차이가 0인 비율이 21%뿐(페이퍼 콜라주 샘플은 56%) | 배경 상시 회전 |
| 3 | **회전하는 선버스트(방사선) 배경**: 거의 모든 장면의 바탕. 직선 방사형, 소용돌이형, 큰 해 원 + 방사형 3가지 | 느린 회전 |
| 4 | **레트로 간판 패널**: 사다리꼴로 살짝 기운 크림색 판 + 굵은 남보라 외곽선 + 딱딱한 오프셋 그림자 + 빨간 굵은 글자. 탄성 있게 "뽕" 튀어나온다 | 팝 0.25~0.35초 |
| 5 | **장면 전환 2종을 번갈아**: ① 원형 아이리스(가운데 잉크 스플랫 → 원이 커지며 다음 장면), ② 구겨진 종이 구멍(구겨진 흰 종이가 벌어지며 다음 장면이 드러남) | 0.5~0.8초 |
| 6 | **필름 룩이 화면 전체를 덮는다**: 둥근 모서리 필름 게이트, 강한 비네트, **분홍·초록·보라 라이트 릭이 계속 흐르며 색이 순환**, 밝기 깜빡임, 종이 접힌 자국 | 상시 |
| 7 | **팝아트 컬러와 일러스트 혼합**: 벡터 일러스트(자동차, 별, 필름 릴)와 실사 컷아웃(흑백 인물, TV, 카메라)을 섞는다. 하프톤 망점, 4포인트 반짝이 별 | — |

**다른 두 샘플과의 차이**
| | Vox Typography | Paper Collage | **Retro Collage Opener** |
|---|---|---|---|
| 분위기 | 차분한 저널리즘 | 따뜻한 수공예 | **시끄럽고 신나는 50~70년대 광고** |
| 배경 | 모눈종이(정지) | 크라프트지(3fps 보일) | **회전하는 선버스트 + 라이트 릭** |
| 전환 | 하드컷 | 밀기·찢기·구멍 | **원형 아이리스 ↔ 구겨진 종이 구멍** |
| 글자 | 명조 + 빨간 손그림 | 손글씨 + 붓 | **간판 패널 + 3D 압출 필기체 + 마퀴** |
| 정지 | 길게(1~2초) | 중간(1.5~2초) | **거의 없음(계속 움직임)** |

## 4. 모션 패턴 카탈로그

프레임은 24fps 기준. 변화량은 108p 흑백으로 줄인 프레임 사이 평균 밝기 차이(짝수 프레임만 의미 있음 — 투스).

### R1. 회전 선버스트 배경 (Rotating Sunburst) — 거의 모든 장면
- **동작:** 방사형 줄무늬가 화면 중심(또는 해 원 중심)을 기준으로 **천천히 계속 회전**한다. 소용돌이형(S8)은 줄이 휘어 있다.
- **속도:** 약 분당 3~6바퀴(느림). 12fps 스텝이라 조금씩 톡톡 돈다.
- **근거:** "유지" 구간에도 짝수 프레임 변화량이 10~17로 유지(S9~S10 프레임 740~936).
- **포인트:** 이 스타일에서 "정지 화면"을 없애는 1순위 장치.

### R2. 간판 팝 (Sign Panel Pop) — 모든 간판
- **동작:** 기울어진 간판 판이 0%에서 튀어나와 약 120~125%까지 커졌다가 95% → 100%로 **탄성 있게 안착**. 판과 글자가 함께 움직이고, 판마다 약간 다른 기울기로 멈춘다.
- **길이:** 약 0.25~0.35초(3~4스텝). 여러 판이면 0.08~0.17초 간격으로 차례로(d1_intro_sign 3~9칸).
- **After Effects:** Scale 키프레임 0→125→95→100(Ease), 또는 Overshoot 익스프레션.

### R3. 잉크 스플랫 방사 (Ink Splat Burst) — S1 시작, 아이리스 전환의 가운데
- **동작:** 가운데 작은 **방사형 가시 모양 잉크**가 "퍽" 터지고(2~3스텝), 곧바로 그 자리에서 선버스트나 원이 퍼져 나온다(d1_intro_sign 0~2칸, d3_iris 5~7칸).
- **길이:** 약 0.2~0.3초.
- **포인트:** "여기서 새 장면이 시작된다"는 신호. 전환의 시작점을 한 점으로 모아 준다.

### R4. 원형 아이리스 전환 (Circle Iris Wipe) — S4→S5, S6→S7, S7→S8, S9→S10
- **동작:** 화면 가운데(또는 약간 옆)에서 **다음 장면 색의 원이 커지며** 이전 장면을 덮는다. 원 안에 잉크 스플랫(R3)이 있고, 원이 화면을 다 채우면 다음 장면 요소들이 등장.
- **길이:** 원 확대 약 0.4~0.5초(5~6스텝), 가속형(Ease In)으로 끝에서 빨라짐.
- **근거:** d3_iris 2~7칸(작은 점 → 원 → 화면 가득).

### R5. 구겨진 종이 구멍 전환 (Crumpled Paper Hole) — S1→S2, S2→S3, S5→S6
- **동작:** 화면 한쪽에서 **구겨진 흰 종이가 찢기듯 벌어지며** 구멍이 생기고, 구멍 속에 다음 장면이 보인다. 구멍 속에 작은 구겨진 종이 뭉치가 하나 더 있어 **두 겹으로 벌어진다**(d2_crumple_hole 3~17칸).
- **길이:** 약 0.7~0.8초. 초반 느리게 → 중반 빠르게 → 끝에서 종이 조각이 화면 밖으로 흩어짐.
- **After Effects:** 스톡 "Paper Rip / Crumpled Hole" 영상을 Luma Matte로. 실제 촬영 소스가 핵심.

### R6. 구겨진 종이 펴기 → 오브젝트 등장 (Crumple Unfold Reveal) — S8 카메라
- **동작:** 화면 가운데 **작은 구겨진 종이 뭉치**가 나타나 살짝 흔들리다가, 펴지면서 그 안에서 **카메라 컷아웃이 튀어나오며 커진다**. 동시에 마키 별과 간판이 팝(d5_unfold_camera 5~14칸).
- **길이:** 뭉치 흔들림 약 0.4초 + 펴기·확대 약 0.4초.

### R7. 사진 프레임 슬램 (Tilted Frame Slam) — S4, S7
- **동작:** 파랑·보라 색면이 먼저 기울어진 채 화면에 **쾅 떨어지고**, 이어서 사진 프레임이 그 위에 약간 다른 각도로 떨어져 **두 겹이 어긋나게** 겹친다. 떨어진 뒤 1~2스텝 동안 살짝 크기가 튄다(102→100%)(d4_frame_slam 5~12칸).
- **길이:** 색면 약 0.15초, 사진 약 0.2초, 간격 약 0.1초.
- **포인트:** 두 겹 오프셋(색면이 사진보다 약간 크고 기울기가 다름)이 레트로 인쇄 어긋남 느낌을 준다.

### R8. 인물·원 솟아오르기 (Circle + Cutout Rise) — S5
- **동작:** 노란 원(해)이 가운데에서 커지고(Ease Out, 약 0.3초), 흑백 인물 컷아웃이 **화면 아래에서 원 앞으로 솟아오른다**(약 0.4초, 살짝 기울었다가 바로 섬)(d3_iris 8~12칸).
- **포인트:** 페이퍼 콜라주 샘플의 "블롭 + 인물"과 같은 구조지만 블롭 대신 **완벽한 원**을 쓴다.

### R9. 3D 압출 필기체 쓰기 (Extruded Script Write-On) — "Groovy", "Good vibes", "Thanks for watching"
- **동작:** 굵은 레트로 필기체(얼굴면 노랑·흰색, 깊이면 빨강·자주로 대각선 압출)가 **한 글자씩 써지듯** 나타난다. 두 번째 줄은 첫 줄이 끝나기 전에 시작.
- **길이:** 단어당 약 0.4~0.6초.
- **포인트:** 압출(깊이면)이 있어 평면 필기체보다 훨씬 "간판"스럽다.

### R10. 키네틱 마퀴 (Scrolling Repeat Rows) — S9
- **동작:** 찢어진 종이 띠 3줄 위에 같은 문구가 반복되며 **줄마다 반대 방향으로 흐른다**(가운데 줄은 빨강 강조, 위아래 줄은 흰 글자). 처음엔 작고 흩어진 글자로 시작해 0.5초 만에 줄이 가득 찬다(d6_marquee 3~9칸).
- **속도:** 초당 화면 폭의 약 10~15%.
- **포인트:** 마지막 엔딩 직전 "브랜드 반복" 구간. 짧게(3~4초).

### R11. 필름 룩 오버레이 (Film Gate + Light Leak Cycle) — 전체

## 6. 우리 파이프라인(Python)에 적용하는 방법

아래 함수는 테스트해서 동작을 확인했습니다. **제작 기준**을 함께 적용합니다.

| 대상 | Posterize Time | 비고 |
|---|---|---|
| **모든 요소(elements)** — 간판, 글자, 컷아웃, 별·아이콘, 사진 프레임, 전환(아이리스·구겨진 종이) | **12fps** | 샘플과 같은 투스 리듬 |
| **배경** — 선버스트 회전, 종이 텍스처, 색면 배경 | **4fps** | 배경만 더 뚝뚝 끊겨 요소와 리듬 차이가 생김 |
| 위글 | wiggle(1,10) | 모든 위글 모션 |
| 필름 그레인·라이트 릭(R11) | 오버레이 | 요소 기준(12fps)으로 갱신 |

구현: 한 프레임을 그릴 때 배경은 `t_bg = floor(t*4)/4`, 요소는 `t_el = floor(t*12)/12` 시각으로 따로 계산해 합성합니다. 선버스트는 초당 4번만 돌아가므로 회전 속도를 조금 크게(rpm 6~8) 잡으면 움직임이 분명하게 보입니다.

```python
import math, random
import numpy as np
from PIL import Image, ImageDraw, ImageFilter

W, H = 1920, 1080

def lerp(a, b, t):
    return a + (b - a) * t

def sunburst(t, colors, n=16, rpm=4, cx=W / 2, cy=H / 2, swirl=0.0):
    """R1: 회전하는 선버스트 배경. swirl>0이면 소용돌이형."""
    img = Image.new("RGB", (W, H), colors[0])
    d = ImageDraw.Draw(img)
    rot = t * rpm * 2 * math.pi / 60
    R = math.hypot(W, H)
    for i in range(n):
        a0 = rot + 2 * math.pi * i / n
        a1 = a0 + math.pi / n
        pts = [(cx, cy)]
        for k in range(24):
            r = R * (k + 1) / 24
            a = a0 + swirl * r / R
            pts.append((cx + r * math.cos(a), cy + r * math.sin(a)))
        for k in range(23, -1, -1):
            r = R * (k + 1) / 24
            a = a1 + swirl * r / R
            pts.append((cx + r * math.cos(a), cy + r * math.sin(a)))
        d.polygon(pts, fill=colors[1 + i % (len(colors) - 1)])
    return img

def iris_mask(p, cx=W / 2, cy=H / 2):
    """R4: 원형 아이리스 와이프 마스크(원 안이 다음 장면). p: 0~1, 끝에서 빨라지는 Ease In."""
    m = Image.new("L", (W, H), 0)
    R = math.hypot(W, H) / 2 * 1.05
    r = R * (p ** 1.4)
    ImageDraw.Draw(m).ellipse([cx - r, cy - r, cx + r, cy + r], fill=255)
    return m

def splat(size, color, spikes=28, seed=0):
    """R3: 방사형 잉크 스플랫."""
    rng = random.Random(seed)
    im = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    d = ImageDraw.Draw(im)
    c = size / 2
    for i in range(spikes):
        a = 2 * math.pi * i / spikes + rng.uniform(-0.05, 0.05)
        L = c * rng.uniform(0.55, 0.98)
        d.line([(c, c), (c + L * math.cos(a), c + L * math.sin(a))], fill=color + (255,), width=int(rng.uniform(2, 5)))
    d.ellipse([c - c * 0.12, c - c * 0.12, c + c * 0.12, c + c * 0.12], fill=color + (255,))
    return im

def sign_panel(text, fnt, fg=(200, 50, 50), bg=(250, 240, 228), outline=(50, 40, 60), skew=0.06, pad=40,
               shadow=(12, 14)):
    """R2: 레트로 간판 — 사다리꼴로 기운 판 + 굵은 외곽선 + 딱딱한 오프셋 그림자."""
    l, t, r, b = fnt.getbbox(text)
    w, h = r - l + 2 * pad, b - t + 2 * pad
    sx = int(w * skew)
    out = Image.new("RGBA", (w + sx * 2 + shadow[0] + 20, h + shadow[1] + 20), (0, 0, 0, 0))
    d = ImageDraw.Draw(out)
    poly = [(10 + sx, 10), (10 + w + sx * 2, 10 + h * 0.08), (10 + w + sx, 10 + h), (10, 10 + h * 0.92)]
    d.polygon([(x + shadow[0], y + shadow[1]) for x, y in poly], fill=outline + (255,))
    d.polygon(poly, fill=bg + (255,), outline=outline + (255,), width=7)
    d.text((10 + sx + pad - l, 10 + pad - t), text, font=fnt, fill=fg)
    return out

def pop_scale(p, overshoot=1.25):
    """R2: 0 → 125% → 95% → 100% 탄성 팝 (p: 0~1)."""
    p = min(max(p, 0), 1)
    if p < 0.5:
        return overshoot * (p / 0.5) ** 0.7
    if p < 0.75:
        return lerp(overshoot, 0.95, (p - 0.5) / 0.25)
    return lerp(0.95, 1.0, (p - 0.75) / 0.25)

def extrude_text(text, fnt, face, side, depth=14, angle=(1, 1)):
    """R9: 3D 압출 필기체 — 같은 글자를 대각선으로 여러 번 겹쳐 깊이면을 만든다."""
    l, t, r, b = fnt.getbbox(text)
    im = Image.new("RGBA", (r - l + depth + 40, b - t + depth + 40), (0, 0, 0, 0))
    d = ImageDraw.Draw(im)
    for k in range(depth, 0, -1):
        d.text((20 - l + k * angle[0], 20 - t + k * angle[1]), text, font=fnt, fill=side)
    d.text((20 - l, 20 - t), text, font=fnt, fill=face)
    return im

def marquee_rows(t, rows, speed=260):
    """R10: 줄마다 반대 방향으로 흐르는 반복 문구. rows=[(sprite, y, +1/-1)]."""
    layer = Image.new("RGBA", (W, H), (0, 0, 0, 0))
    for spr, y, dr in rows:
        x = -((t * speed * dr) % spr.width)
        while x < W:
            layer.paste(spr, (int(x), int(y)), spr)
            x += spr.width
    return layer

def film_look(img, t, seed=0, leak_strength=0.22):
    """R11: 둥근 모서리 게이트 + 비네트 + 떠도는 컬러 라이트 릭(Screen) + 밝기 깜빡임."""
    a = np.asarray(img.convert("RGB"), np.float32)
    yy, xx = np.mgrid[0:H, 0:W].astype(np.float32)
    rng = random.Random(seed)
    leak = np.zeros_like(a)
    for i, col in enumerate([(255, 60, 160), (80, 255, 120), (120, 80, 255)]):
        ph = rng.uniform(0, 6.28)
        cx = W * (0.5 + 0.55 * math.sin(t * 0.35 + ph + i * 2.1))
        cy = H * (0.5 + 0.5 * math.cos(t * 0.27 + ph * 1.3))
        s = W * 0.35
        leak += np.exp(-(((xx - cx) ** 2 + (yy - cy) ** 2) / (2 * s * s)))[..., None] * np.array(col, np.float32)
    a = 255 - (255 - a) * (255 - np.clip(leak * leak_strength, 0, 255)) / 255
    a *= 1 + 0.03 * random.Random(int(t * 12)).uniform(-1, 1)
    v = 1 - 0.35 * (((xx - W / 2) / (W / 2)) ** 2 + ((yy - H / 2) / (H / 2)) ** 2)
    a *= np.clip(v, 0, 1)[..., None]
    gate = Image.new("L", (W, H), 0)
    ImageDraw.Draw(gate).rounded_rectangle([18, 14, W - 18, H - 14], radius=46, fill=255)
    g = np.asarray(gate.filter(ImageFilter.GaussianBlur(6)), np.float32)[..., None] / 255
    a = a * g + np.array([18, 10, 24], np.float32) * (1 - g)
    return Image.fromarray(a.clip(0, 255).astype(np.uint8))
```

**한 섹션 조립 예시 (약 3.5초)**
1. `t=0.0` 이전 장면 위에 잉크 스플랫(R3) → 원형 아이리스(R4, 0.45초)로 새 선버스트 배경(R1)
2. `t=0.4` 해 원이 커지고(R8), 컷아웃이 아래에서 솟음(요소 12fps)
3. `t=0.8~1.3` 간판 판들이 0.1초 간격으로 팝(R2), 3D 필기체 쓰기(R9)
4. `t=1.3~3.0` 유지 — 선버스트 회전(배경 4fps), 별 트윙클(R12)·아이콘 wiggle(1,10)(요소 12fps), 라이트 릭(R11)은 계속
5. 다음 섹션으로 구겨진 종이 구멍(R5, 아래 8장의 실제 소스) 또는 아이리스(R4)를 번갈아
6. 모든 프레임 마지막에 `film_look()`(R11)을 씌운다

**구현 난이도 메모:** 구겨진 종이 구멍(R5)과 종이 펴기(R6)는 실제 종이를 촬영한 소스가 있어야 샘플 수준이 나온다. → 8장의 그린/블루 소스를 사용.
