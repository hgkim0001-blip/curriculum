# Retro Paper Collage — 모션 패턴 분석

- 분석 대상: `preview_540p_crf22_higher_quality.mp4`
- 영상 정보: 960×540, 30fps, 25.0초, 749프레임
- 분석 방법: ffmpeg 장면 전환 검출, 프레임 간 변화량 측정(스텝 주기·움직임 곡선), 6프레임 간격 콘택트 시트, 전환 구간 프레임 단위 상세 시트
- 근거 이미지: `분석자료_콜라주/` 폴더
  - `sheet_01~05.png`: 6프레임 간격 전체 흐름. 칸 번호 × 6 = 원본 프레임 번호
  - `d1~d6_*.png`: 도입, 가로 밀기 전환, 구겨진 종이 구멍 전환, 찢어진 종이 올라오기 전환, 텍스트 등장, 엔딩 필기체를 프레임 단위(또는 2프레임 단위)로 본 시트

## 1. 핵심 요약 (이 6가지만 지키면 이 스타일이 나온다)

| # | 원칙 | 수치 |
|---|---|---|
| 1 | **12fps 스텝 애니메이션**: 모든 움직임이 2-3-2-3 프레임마다 한 번씩 바뀐다. 프레임 차이가 0인 비율이 56% | Posterize Time **12fps** |
| 2 | **종이 질감 보일(Boil)**: 배경 종이 텍스처가 약 10프레임(3fps)마다 다른 종이로 바뀐다. 정지 구간에도 화면이 살아 있다 | 텍스처 3~4장 순환, 3fps |
| 3 | **찢어진 종이가 모든 것의 경계**: 인물 등장, 장면 전환, 사진 분할이 모두 찢어진 종이 가장자리(흰 섬유)로 처리된다 | 찢긴 가장자리 + 흰 종이층 |
| 4 | **아래에서 위로 쌓는다**: 색 블롭 → 인물 컷아웃 → 낙서 선 → 라벨 → 문구 순서로 아래에서 튀어 오르며 붙는다 | 요소 간격 0.2~0.4초 |
| 5 | **문구는 도장처럼 찍히고, 필기체는 써진다**: 굵은 글자는 흐림에서 선명으로 툭 찍히고, 필기체는 한 획씩 써진다 | 찍기 0.2초, 쓰기 단어당 0.3~0.5초 |
| 6 | **전환은 종이 물리 동작으로**: 밀기, 찢어진 종이가 덮기, 구겨진 종이 구멍으로 빨려 들어가기 | 전환 0.5~1.0초 |

**Vox Typography 샘플과의 차이:** Vox는 흑백·명조·빨간 손그림·하드컷(차분하고 저널리즘적)인 반면, 이 샘플은 **따뜻한 크라프트지·원색 블롭·손글씨 폰트·물리적 종이 전환**(경쾌하고 SNS 광고적)입니다.

## 2. 비주얼 시스템

| 요소 | 특징 |
|---|---|
| 배경 | 크라프트지, 구겨진 종이, 줄무늬 종이 등 **따뜻한 베이지 종이 텍스처 여러 장**을 번갈아 사용(보일) |
| 인물 | **세피아·흑백 컷아웃**(배경 제거). 상반신이 화면 아래쪽에 걸쳐 있고, 뒤에 **원색 유기적 블롭**(오렌지·청록)이 받침 |
| 사진 | 전체 화면 세피아 사진에 **하프톤 망점** 질감, 찢어진 종이 조각으로 대각선 분할 |
| 컬러 | 번트 오렌지, 머스터드 옐로, 청록, 올리브 그린, 벽돌색 빨강, 연분홍, 청색. 채도는 약간 낮춘 레트로 톤 |
| 타이포 | ① 굵은 손글씨 대문자(러프한 가장자리), ② 필기체 스크립트, ③ 흰 종이 알약(pill) 라벨 위의 문구 |
| 배경 대형 글자 | 화면 뒤에 **아주 큰 그런지 질감 글자**("PRO", "MA" 등)를 옅게 깔아 깊이감을 준다 |
| 장식 | 청록·오렌지 **낙서 곡선**(손으로 그은 선), 노란 붓 터치 하이라이트, 대각선 색종이 띠 |
| 질감 | 필름 그레인, 종이 섬유, 하프톤. 모든 면에 질감이 있고 매끈한 벡터 면이 없다 |

## 4. 모션 패턴 카탈로그

프레임은 30fps 기준입니다. 변화량은 108p 흑백으로 줄인 프레임 사이의 평균 밝기 차이입니다.

### P1. 블롭 솟아오르기 (Blob Rise) — S1, S2, S5 도입
- **동작:** 원색 유기적 블롭이 화면 아래 밖에서 위로 솟아올라 인물 뒤 자리에 멈춘다. 모양이 살짝 꿀렁이며 커진다(스케일 약 80%에서 100%).
- **길이:** 약 0.35초(4스텝). 곡선은 Ease Out(d1_intro 4~10칸).
- **포인트:** 블롭이 **먼저** 나와 인물이 설 무대를 만든다.

### P2. 찢어진 종이 마스크 리빌 (Torn-Paper Mask Reveal) — 모든 인물 등장
- **동작:** 인물 컷아웃이 아래에서 올라오는데, 머리 위를 **찢어진 흰 종이 띠**가 덮고 있다. 인물이 올라가는 동안 종이 띠가 조금씩 위로 벗겨지며 얼굴이 마지막에 드러난다(d1_intro 8~24칸, d4_tear 6~24칸).
- **길이:** 약 0.8~1.0초. 인물 위치는 Ease Out이고, 종이 띠는 조금 늦게 따라간다(약 2스텝 지연).
- **포인트:** "얼굴을 마지막에 보여 주는" 기대감 연출. 종이 띠의 흰 섬유 가장자리가 핵심.
- **After Effects:** 찢어진 종이 PNG를 Track Matte(Alpha Inverted)로 쓰고 Position을 인물보다 늦게 키프레임.

### P3. 낙서 선 그리기 (Doodle Line Draw-On) — S1, S2, S5
- **동작:** 청록·오렌지 굵은 곡선이 화면 가장자리에서 시작해 그려진다(d5_type 0~9칸).
- **길이:** 약 0.5~0.8초. 12fps 스텝이라 획이 뚝뚝 끊기며 자라는 느낌.
- **After Effects:** Shape Layer Trim Paths(End 0→100%), 둥근 끝(Round Cap).

### P4. 알약 라벨 → 문구 (Pill Label Pop) — S1 "How is", S4 "Unlock endless possibilities"
- **동작:** ① 빈 **흰 종이 알약**이 먼저 튀어나오고(스케일 0→110→100%), ② 2~3스텝 뒤 그 위에 글자가 찍힌다.
- **길이:** 알약 약 0.2초, 글자 약 0.2초. 라벨은 약간 기울어져 있다(±5°).

### P5. 도장 찍기 텍스트 (Stamp-In Text) — "WEEKEND", "INNOVATIVE", "EXPLORE"
- **동작:** 굵은 대문자가 **흐리고 약간 크게**(약 110%) 나타났다가 1~2스텝 만에 선명하고 원래 크기로 툭 자리 잡는다(d5_type 17~19칸).
- **길이:** 약 0.17~0.25초(2~3스텝).
- **포인트:** 이동 없이 초점과 크기만 바뀐다. 짧고 단단한 느낌.

### P6. 필기체 쓰기 (Script Write-On) — "your", "doodle style", "Thanks for Watching"
- **동작:** 필기체가 **획 순서대로** 써진다(d6_end 15~24칸). 여러 단어가 있으면 한 단어가 끝나기 전에 다음 줄이 시작되기도 한다.
- **길이:** 단어당 약 0.3~0.5초. "Thanks for Watching" 전체 약 1.4초.
- **After Effects:** Stroke 효과 + 마스크 경로, 또는 Write-on 플러그인. Python에서는 글자 폭 방향으로 늘어나는 와이프 마스크로 흉내 낼 수 있다.

### P7. 붓 터치 하이라이트 (Brush Swipe Behind Text) — "Going?", "photo effect"
- **동작:** 노란 붓 자국이 왼쪽에서 오른쪽으로 칠해지고(약 0.2초), 그 위에 글자가 찍힌다(d5_type 22~24칸).
- **포인트:** Vox 샘플의 빨간 타원 역할을 이 스타일에서는 노란 붓 자국이 맡는다.

### P8. 배경 대형 글자 (Giant Background Type) — S1 "PRO", S5 "MA"
- **동작:** 인물 뒤에 화면 높이의 70% 정도 되는 **그런지 질감 대형 글자**가 한 번에 나타난다(블러 없이 컷인). 투명도 약 60~70%로 옅게.
- **포인트:** 움직이지 않는 깊이 레이어. 주인공 문구보다 한 단계 뒤에 있다.

### P9. 반복 적층 텍스트 (Kinetic Repeat Stack) — S5 "INNOVATIVE"
- **동작:** 같은 단어가 인물 뒤에 **여러 줄로 반복**되고, 줄마다 약 1~2스텝 간격으로 아래에서 위로 쌓인다. 맨 아래에는 빨간 띠 위에 흰색으로 같은 단어를 한 번 더 크게 둔다.
- **길이:** 전체 약 0.6~0.8초.
- **포인트:** 한 단어를 리듬 있게 강조하는 방법.

### P10. 대각선 색종이 띠 스윕 (Diagonal Paper Band Sweep) — S3
- **동작:** 빨강·노랑·분홍·초록 색종이 띠가 대각선 방향으로 아래에서 쓸려 올라오고, 띠 하나에 문구 한 줄이 함께 올라온다.
- **길이:** 줄마다 약 0.2~0.3초 간격, 전체 약 1.2초.

### P11. 가로·세로 밀기 전환 (Paper Push) — S1→S2(가로), S2→S3(세로)
- **동작:** 현재 장면 전체가 **한 장의 종이처럼** 옆(또는 위)으로 밀려 나가고, 다음 장면의 종이가 붙어서 들어온다. 두 종이 사이 경계에 종이 가장자리 그림자가 보인다(d2_wipe1).
- **길이:** 약 0.5초. 변화량 52.6 → 32.4 → 21.7 → 17.2 → 15.2 → 11.8 …: 첫 스텝이 가장 크고 이후 감소하는 **Expo Out**.
- **포인트:** 새 장면이 들어오는 도중에 이미 블롭과 인물 등장이 시작된다(겹쳐 진행).

### P12. 구겨진 종이 구멍 전환 (Crumpled Paper Hole) — S3→S4
- **동작:** 작게 구겨진 종이 뭉치가 화면 오른쪽 위에 나타나 중앙으로 오면서 **가운데가 뚫린 구멍**이 된다. 구멍이 점점 커지며 다음 장면(전체 화면 사진)이 구멍 속으로 보이다가 화면을 가득 채운다(d3_crumple).
- **길이:** 약 1.0초(구겨진 뭉치 0.3초, 구멍 확장 0.7초). 변화량 12.4 → 20.2 → 34.8 → 24.1 → 36.1 → 23.6 → 26.1 → 13.8 …: 중간에 최대인 **Ease In-Out**.
- **After Effects:** 구겨진 종이 구멍 스톡 영상 + Luma Matte.

### P13. 찢어진 종이 덮기 전환 (Torn Paper Rise) — S4→S5, S5→S6
- **동작:** 윗부분이 찢어진 새 종이가 **아래에서 위로 올라와** 이전 장면을 덮는다. 찢긴 가장자리가 수평으로 울퉁불퉁하다(d4_tear 2~10칸, d6_end 3~8칸).
- **길이:** 약 0.4~0.5초, Ease Out.
- **포인트:** 새 종이가 다 덮기 전에 다음 장면의 블롭이 이미 그 종이 위에 올라와 있다(전환과 등장을 겹쳐 속도감).

### P14. 사진 찢어 나누기 (Torn Split Photo) — S4
- **동작:** 전체 화면 사진 위로 **대각선 찢김 선** 2개가 생기며, 각 조각이 살짝 다른 색조(세피아/컬러)와 위치로 어긋난다. 하프톤 망점이 조각마다 다르게 보인다.
- **길이:** 찢김 등장 약 0.2초(컷에 가깝다).

### P15. 모서리 색종이 프레임 (Corner Paper Frame) — S6 엔딩
- **동작:** 빨강 → 청 → 초록 → 노랑 순서로 **찢어진 색종이 조각**이 네 모서리에서 하나씩 슬며시 들어와 화면을 액자처럼 감싼다(d6_end 9~17칸).
- **길이:** 조각마다 약 0.3초, 간격 약 0.2초.

### P16. 종이 질감 보일 (Paper Texture Boil) — 전체
- **동작:** 배경 종이 텍스처가 **약 10프레임(3fps)마다** 다른 종이로 바뀐다(예: 크라프트지 → 구겨진 종이 → 줄무늬 종이). 요소는 12fps 스텝으로 아주 조금씩 흔들린다.
- **근거:** 정지 구간(프레임 290~360)에서 변화량 피크가 290, 300, 308, 318, 328, 338, 348, 358로 약 10프레임 주기.
- **포인트:** 이 스타일의 "손으로 만든 스톱모션" 느낌은 12fps 스텝과 이 보일이 함께 만든다.

## 6. 우리 파이프라인(Python)에 적용하는 방법

지금까지 만든 스크립트(`make_video_collage.py`, `make_video_vox_v3.py`)에 붙일 수 있는 형태입니다. `step_time`, `expo_out`은 Vox 문서의 함수를 그대로 씁니다.

```python
import math, random
import numpy as np
from PIL import Image, ImageDraw, ImageFilter

STEP_FPS, BOIL_FPS = 12, 3

def boil_index(t, n_textures=3):
    """P16: 3fps로 배경 종이 텍스처를 순환."""
    return int(t * BOIL_FPS) % n_textures

def torn_edge_mask(w, h, cut_y, seed=0, jag=10, step=14):
    """P2·P13: cut_y 위쪽을 찢어진 가장자리로 잘라 낸 마스크(L). 아래쪽이 255."""
    rng = random.Random(seed)
    pts = [(0, h)]
    for x in range(0, w + step, step):
        pts.append((x, cut_y + rng.uniform(-jag, jag)))
    pts.append((w, h))
    m = Image.new("L", (w, h), 0)
    ImageDraw.Draw(m).polygon(pts, fill=255)
    return m

def torn_paper_sheet(w, h, color, seed=0, fiber=8):
    """P13·P15: 윗변이 찢어지고 흰 섬유층이 보이는 종이 한 장(RGBA)."""
    out = Image.new("RGBA", (w, h + fiber * 2), (0, 0, 0, 0))
    white = torn_edge_mask(w, h + fiber * 2, fiber, seed, jag=fiber + 4)
    body = torn_edge_mask(w, h + fiber * 2, fiber * 2, seed + 1, jag=fiber)
    out.paste(Image.new("RGBA", out.size, (250, 247, 238, 255)), (0, 0), white)
    out.paste(Image.new("RGBA", out.size, color + (255,)), (0, 0), body)
    return out

def stamp_in(sprite, p):
    """P5: 흐리고 110%에서 선명하고 100%로 (p: 0~1)."""
    s = 1.1 - 0.1 * min(max(p, 0), 1)
    im = sprite.resize((max(1, int(sprite.width * s)), max(1, int(sprite.height * s))), Image.BICUBIC)
    r = 6 * (1 - min(max(p, 0), 1))
    return im.filter(ImageFilter.GaussianBlur(r)) if r > 0.3 else im

def script_write_on(sprite, p):
    """P6: 필기체를 왼쪽부터 드러낸다(획 순서 근사). 끝부분은 부드럽게."""
    w, h = sprite.size
    edge = int(w * min(max(p, 0), 1))
    m = np.zeros((h, w), np.float32)
    m[:, :edge] = 1
    feather = 18
    lo = max(0, edge - feather)
    if edge > lo:
        m[:, lo:edge] = np.linspace(1, 0, edge - lo)[None, :]
    a = np.asarray(sprite.getchannel("A"), np.float32) * m
    out = sprite.copy()
    out.putalpha(Image.fromarray(a.astype(np.uint8)))
    return out

def hole_mask(w, h, cx, cy, r, seed=0, n=90):
    """P12: 가장자리가 잔잔하게 울퉁불퉁한 구멍 마스크(구멍 안이 255). r을 키우며 다음 장면을 드러낸다."""
    rng = random.Random(seed)
    pts = []
    for i in range(n):
        a = 2 * math.pi * i / n
        rr = r * (1 + 0.05 * math.sin(a * 3 + seed) + 0.03 * math.sin(a * 11) + rng.uniform(-0.035, 0.035))
        pts.append((cx + rr * math.cos(a), cy + rr * 0.8 * math.sin(a)))
    m = Image.new("L", (w, h), 0)
    ImageDraw.Draw(m).polygon(pts, fill=255)
    return m
```

**적용 순서 예시 (한 섹션, 약 4초)**
1. `t=0.0` 이전 장면을 찢어진 종이가 아래서 덮으며 전환(P13, 0.45초)
2. `t=0.15` 원색 블롭이 솟아오름(P1)
3. `t=0.35` 사진 컷아웃이 올라오며 찢어진 종이 띠가 벗겨짐(P2, 0.9초)
4. `t=0.9` 낙서 선 그리기(P3), 배경 대형 글자 컷인(P8)
5. `t=1.2~2.0` 알약 라벨(P4) → 굵은 문구 도장(P5) → 필기체 쓰기(P6) → 노란 붓 하이라이트(P7)
6. `t=2.0~3.6` 정지(12fps 흔들림 + 3fps 텍스처 보일)
7. 다음 섹션으로 밀기(P11), 찢어진 종이 덮기(P13), 또는 구겨진 종이 구멍(P12)
