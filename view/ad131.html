Cinema 4D와 Claude 연결 가이드

2026-10-04 · 김사부

개요

Cinema 4D 2024에서는 오픈소스 플러그인 cinema4d-mcp로 Claude Desktop과 연결합니다. 이 문서는 2026년 10월 4일 Windows PC에서 실제로 성공한 절차를 정리한 것입니다.

연결 방식은 C4D 버전에 따라 두 가지입니다.

구분 오픈소스 플러그인 공식 내장 MCP
대상 버전 C4D 2024.0 이상 C4D 2026.4 이상
설치 난이도 Python 설치, 플러그인 복사, 설정 파일 수정 필요 Preferences에서 체크 한 번
추가 비용 없음 (기존 라이선스 사용) 2026 구독 필요
이 문서에서 검증 직접 설치하고 작업까지 확인 직접 테스트하지 않음

구조는 세 단계입니다. Claude Desktop이 Python으로 MCP 서버(main.py)를 실행하고, 이 서버가 포트 5555로 C4D 안의 소켓 서버 플러그인과 통신합니다. C4D 2023 이하는 플러그인 지원 대상이 아닙니다.

준비물

아래 네 가지가 PC에 있어야 합니다. 버전은 이번에 성공한 조합입니다.

항목 조건 이번에 쓴 버전
Cinema 4D 2024.0 이상 2024
Claude Desktop 데스크톱 앱 (웹과 모바일은 불가) 최신
Python 3.10 이상, PATH 등록 3.14.7
cinema4d-mcp GitHub ttiimmaacc/cinema4d-mcp 0.1.2

Python 버전은 명령 프롬프트에서 python --version으로 확인합니다. 아무것도 안 나오면 py --version을 입력해 봅니다.

설치 절차 (C4D 2024, 오픈소스 플러그인)

여섯 단계이며, 3단계의 mcp 버전 내리기를 빼먹으면 Claude Desktop에서 서버가 실패합니다.

  1. 저장소 받기. GitHub의 ttiimmaacc/cinema4d-mcp에서 Code → Download ZIP으로 받아 압축을 풉니다. 경로에 한글과 공백이 없어야 합니다. main.py와 pyproject.toml이 있는 폴더가 작업 폴더입니다.

이번 설치 위치: D:\mcp\cinema4d-mcp\cinema4d-mcp-main

  1. 패키지 설치. 명령 프롬프트에서 작업 폴더로 이동해 설치합니다. 다른 드라이브로 갈 때는 cd /d를 씁니다.

cd /d D:\mcp\cinema4d-mcp\cinema4d-mcp-main pip install -e .

마지막 줄에 Successfully installed ... cinema4d-mcp-0.1.2가 나오면 성공입니다.

  1. mcp 패키지를 1.x로 내리기. 2단계에서 mcp 2.3.0이 자동으로 깔리는데, 이 플러그인은 1.x용이라 그대로 두면 서버가 바로 꺼집니다.

pip install "mcp<2"

이번에는 1.30.0이 설치됐습니다. 이 명령은 어느 폴더에서 실행해도 됩니다.

  1. C4D에 플러그인 복사. C4D에서 Edit → Preferences를 열고 왼쪽 아래 Open Preferences Folder를 누릅니다. 열린 폴더의 plugins 폴더에 c4d_plugin\mcp_server_plugin.pyp를 복사하고 C4D를 재시작합니다.

이번 복사 위치: C:\Users\사용자명\AppData\Roaming\Maxon\Maxon Cinema 4D 2024_A5DBFF93\plugins

  1. 소켓 서버 시작. C4D 메뉴 Extensions → Socket Server Plugin을 열고 Start Server를 누릅니다. 창에 Server: Online과 Server started on 127.0.0.1:5555가 보이면 정상입니다.

  2. Claude Desktop에 등록. 설정 → 개발자 → 구성 편집으로 claude_desktop_config.json을 열고, mcpServers 안에 아래 항목을 추가합니다. 이미 다른 서버가 있으면 앞 항목의 } 뒤에 쉼표를 찍고 이어 붙입니다.

json "cinema4d": { "command": "python", "args": [ "D:\\mcp\\cinema4d-mcp\\cinema4d-mcp-main\\main.py" ] }

경로의 역슬래시는 두 개씩 씁니다. 수정 전에 기존 파일을 백업하고, Claude Desktop을 트레이 아이콘 우클릭 → Quit으로 완전히 종료한 뒤 파일을 저장하고 다시 실행합니다.

설정 → 개발자 화면에서 cinema4d가 "실행 중"으로 표시되면 연결이 끝난 것입니다. 새 채팅에서 "시네마4D에 큐브 하나 만들어줘"로 확인합니다.

매번 사용할 때의 순서

설치는 한 번이지만, 소켓 서버는 C4D를 켤 때마다 다시 시작해야 합니다.

  1. C4D를 실행합니다.
  2. Extensions → Socket Server Plugin에서 Start Server를 누릅니다.
  3. Claude Desktop을 실행합니다. C4D 서버를 먼저 켜고 Claude를 나중에 켜는 순서가 안전합니다.
  4. 작업을 요청합니다.

Socket Server Control 창은 최소화해도 연결이 유지됩니다. X로 닫는 것은 권하지 않습니다. 창 왼쪽 위 줄 세 개 아이콘을 드래그해 레이아웃에 도킹하고 Window → Customization → Save as Startup Layout으로 저장하면 화면을 가리지 않습니다.

문제 해결

이번 설치에서 실제로 겪은 문제는 첫 줄의 mcp 버전 하나였고, 나머지는 같은 구조에서 흔히 생기는 경우입니다.

증상 원인 해결
Claude Desktop에 cinema4d "실패", Server disconnected mcp 패키지가 2.x로 설치됨 pip install "mcp<2" 실행 후 Claude Desktop 재시작
개발자 화면에 cinema4d가 안 보임 JSON 문법 오류(쉼표, 괄호) 또는 경로 오타 설정 파일 문법 확인, 역슬래시 두 개씩 썼는지 확인
서버는 실행 중인데 명령이 안 먹음 C4D에서 Start Server를 안 눌렀음 Socket Server Control에서 Online 확인
연결 오류 방화벽이 5555 포트 차단 Windows 방화벽 허용 창에서 액세스 허용
python을 찾을 수 없음 PATH 미등록 where python으로 경로 확인 후 command에 전체 경로 입력
Extensions 메뉴에 플러그인이 없음 복사 위치가 다름 Open Preferences Folder로 연 폴더의 plugins에 넣었는지 확인

Claude를 거치지 않고 서버만 따로 점검하려면 작업 폴더에서 python main.py를 실행합니다. Successfully connected to Cinema 4D socket!이 나오면 정상이고, Ctrl+C로 종료합니다. 빨간 Traceback이 나오면 그 내용이 원인입니다.

C4D 2026.4 이상: 공식 내장 MCP

C4D 2026.4부터는 MCP가 기본 내장되어 Python 설치나 설정 파일 수정이 필요 없습니다. 이 방식은 직접 테스트하지 않았고, Maxon 공개 안내를 기준으로 적었습니다. 설치 전에 Maxon 공식 문서로 다시 확인하세요.

  1. Claude Desktop을 설치하고 로그인합니다.
  2. C4D의 Preferences → MCP에서 서버를 활성화하고 클라이언트로 Claude를 지정합니다. 기본값은 꺼져 있습니다.
  3. Claude Desktop을 재시작합니다.

허용할 도구 범위와 Python 실행 허용 여부를 Preferences에서 제한할 수 있어, 실습실에서는 권한을 좁혀 두기 좋습니다.

도입 전 확인할 것:

  • 2026 초기 버전이면 2026.4 이상으로 업데이트해야 합니다.
  • 2024 영구 라이선스와 별개로 2026 구독이 필요합니다. 신규 Maxon 계정은 14일 무료 체험으로 먼저 시험해 볼 수 있습니다.
  • 훈련기관의 교육용 실습실 라이선스 적용 여부는 한국 총판에 문의해야 합니다.

활용 예시와 한계

연결 당일에 아래 작업을 모두 대화만으로 진행했습니다.

작업 내용
모그라프 큐브를 클로너로 5x5 배열, 랜덤 이펙터, 재질 적용
리깅 프리미티브로 마네킹 제작, 조인트 22개, 웨이트와 Skin 바인딩
캐릭터 애니메이션 300프레임 걷기 사이클, 전진 이동
배경과 조명 도로와 건물 29동, 주광과 보조광, 그림자
카메라 오비트, 달리, 드론 풀백 샷
기존 프로젝트 수정 해안가 장면에 로우폴리 인물 추가, 갈매기 비행경로 변경, 야간씬 제작
파일과 렌더 프로젝트 복사본 저장, Render Queue로 MP4 렌더 실행

쓰면서 확인한 한계:

  • 전용 도구만으로는 부족합니다. 큐브 생성 같은 단순 작업은 전용 도구로 되지만, 계층 구성과 세부 수치 조정은 대부분 Python 스크립트 실행 도구로 처리했습니다.
  • 내장 렌더 미리보기 도구가 실패했습니다. 메모리 부족 또는 이미지 미반환 오류가 났습니다. Python으로 작은 해상도 렌더를 직접 뽑아 확인하는 방식으로 우회했습니다.
  • Claude는 뷰포트를 직접 보지 못합니다. 확인용 렌더를 뽑기 전에는 좌표 계산으로만 검증하기 때문에, 형태나 색이 어색한지는 사람이 화면을 보고 알려 줘야 빠릅니다.
  • 스크립트 보안 필터가 있습니다. 플러그인이 import os 같은 일부 구문을 차단합니다. 폴더 생성은 pathlib로 처리했습니다.
  • 긴 렌더 중에는 C4D가 응답하지 않습니다. 애니메이션 렌더는 Render Queue에 걸어 두고, 끝난 뒤에 다음 요청을 보내야 합니다.
  • 수정은 되돌릴 수 있게 요청하세요. 원본 파일을 바로 고치기보다 복사본을 만들어 작업하는 편이 안전합니다.
