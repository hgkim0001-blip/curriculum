1. 핵심 요약 (이 5가지만 지키면 이 스타일이 나온다)

# 원칙 수치
1 12fps 스텝 애니메이션: 영상은 29.97fps지만 움직임은 3-2-3-2 프레임마다 한 번씩 바뀐다 Posterize Time 12fps
2 빠르게 들어오고 천천히 멈춘다: 첫 0.2초에 이동의 대부분을 끝내고, 나머지는 길게 감속 Ease-out (Expo 계열), 0.6~1.1초
3 움직이는 동안에는 흐리다: 빠른 이동에는 모션 블러, 등장·정착할 때는 흐림에서 선명으로 등장 블러 0.2~0.4초
4 빨간 손그림 한 가지만 강조색으로: 동그라미, 화살표, 밑줄, 취소선이 그려지듯 나타난다 선 그리기 0.4~0.6초
5 짧게 만들고 길게 멈춘다: 각 섹션은 약 1초 동안 요소를 쌓고, 1~2초 멈춘 뒤 하드컷 섹션 2.6~5초

2. 비주얼 시스템

요소 특징
배경 밝은 회백색 종이 + 가는 회색 모눈(그리드). 섹션이 바뀔 때 요소 없이 빈 모눈만 1~3프레임 보인다
사진 흑백 또는 세피아 빈티지 사진. 흰 톱니 테두리(deckled edge), 부드러운 그림자, 하단 캡션(타자기체)
컷아웃 인물이나 신문을 배경 없이 오려서 배치하고, 여러 장을 겹쳐 콜라주로 만든다
제목 명조(Serif, Times 계열) 검정. 핵심 단어만 Bold
본문·캡션 타자기체(Courier 계열) 작은 글씨, 신문 본문은 명조 단락
강조색 빨강 하나만 사용: 손그림 타원, 곡선 화살표, 밑줄, 취소선
질감 필름 그레인, 종이 질감. 정지 구간에도 프레임마다 미세한 노이즈가 있어 화면이 완전히 멈춰 보이지 않는다

4. 모션 패턴 카탈로그

측정한 프레임 간 변화량 곡선을 근거로 정리했습니다. 프레임은 29.97fps 기준입니다.

M1. Whip-In (휙 날아 들어오기) — S1 신문, S5 인물

  • 동작: 화면 밖(아래 또는 옆)에서 빠르게 날아와 약간 기울어진 채 멈춘다.
  • 길이: 이동 약 0.3초(8~10프레임), 정착과 초점 맞추기까지 약 1초.
  • 곡선: 변화량 14.7 → 22.5 → 24.1 → 18.7 → 13.3 → 9.3 → … → 1.6. 첫 3스텝이 최대이고 이후 지수적으로 감소하는 Expo Out.
  • 효과: 이동 방향으로 강한 모션 블러(detail_01의 0.2~0.4초 칸). 멈춘 뒤에도 0.2~0.3초 동안 살짝 흐리다가 선명해진다.
  • After Effects: Position Expo Out + 회전 약 −5°에서 0° + CC Force Motion Blur 또는 Pixel Motion Blur, Camera Lens Blur 반경 8에서 0.

M2. 단어 단위 타이핑 (Word Pop) — 모든 제목과 인용문

  • 동작: 글자가 아니라 단어 단위로 추가된다("What" → "What is" → "What is information?").
  • 간격: 단어 하나에 약 5~8프레임(0.17~0.27초). 긴 문장은 1~3단어씩 묶어서 표시.
  • 효과: 새 단어는 흐림에서 선명으로 들어오고(약 4프레임), 약간 위로 떠오르는 느낌이다.
  • After Effects: Text Animator에서 Range Selector를 Words 단위로, Opacity와 Blur 적용.

M3. 빨간 손그림 선 그리기 (Write-On Annotation) — 모든 섹션

  • 종류: 타원 동그라미, 곡선 화살표(끝에 화살촉), 밑줄, 취소선.
  • 동작: 선이 한쪽 끝에서부터 그려진다. 타원은 시작점과 끝점이 겹치지 않고 튀어나오게 그려서 손으로 그린 느낌을 낸다.
  • 길이: 타원 약 0.4~0.6초. 화살표는 타원이 끝나자마자 이어서 약 0.3초.
  • 순서: 텍스트가 다 표시된 직후 시작한다(0.1~0.2초 간격).
  • After Effects: Shape Layer의 Trim Paths(End 0→100%, Ease Out)와 Stroke Taper.

M4. Slide Push (밀고 들어오기) — S3 사진 카드

  • 동작: 카드가 화면 오른쪽 밖에서 수평으로 들어와 기존 텍스트를 덮는다. 텍스트는 가려진 뒤 사라진다.
  • 길이: 약 0.7초(detail_02). 앞쪽 0.2초에 이동의 약 70%를 끝낸다.
  • 곡선: Expo Out.

M5. Zoom-Through 매치컷 (사진 속으로 들어갔다 나오기) — S3에서 S4로

  • 동작: 사진 카드로 카메라가 줌인해 사진이 화면을 가득 채운다(약 0.8초). 그 순간 다음 섹션의 전체 화면 사진으로 하드컷하고, 이어서 줌아웃해 그 사진이 콜라주 속 한 장이 된다.
  • 곡선: 줌인의 변화량은 2 → 10 → 31 → 58 → 49 → 40 → 28 → 18 → 12 → 7 → 3.6(짧게 가속한 뒤 길게 감속). 줌아웃도 같은 모양.
  • 포인트: 두 장면을 "가득 찬 사진"으로 연결하므로 컷이 튀지 않는다.

M6. Snap Zoom Push-In (빠른 확대 강조) — S6 엔딩

  • 동작: 문서 전체가 약 2배로 거의 일정한 속도로 확대되다가 툭 멈춘다.
  • 길이: 약 0.55초(16프레임).
  • 곡선: 변화량 44 → 50 → 46 → 46 → 47 → 41 → 33 → 7. 선형에 가깝고 마지막 1~2스텝에서 급정지하는 Linear에 짧은 Ease Out.
  • 용도: 빨간 표시가 있는 핵심 구절을 화면 중앙에 크게 보여 주는 마무리.

M7. 카메라 줌아웃과 흐림 (Pull-Back Defocus) — S2 후반

  • 동작: 콜라주 전체가 살짝 작아지며(약 90%) 멀어지는데, 움직이는 동안 전체가 흐려졌다가 멈추면 선명해진다.
  • 곡선: 변화량 4 → 9 → 15 → 25 → 33 → 25 → 16 → 10 → 6.5 → 4.5. 앞쪽 3분의 1 지점에서 최고 속도가 되는 Ease In-Out, 약 1초.

M8. 팝인 콜라주 (Scatter Pop-In) — S2

  • 동작: 사진, 문서 조각, 텍스트 블록이 화면 가장자리에서 순서대로 튀어 들어온다. 각 요소는 약 0.2초 간격.
  • 각 요소는 M1(Whip-In)의 짧은 버전이다: 모션 블러와 Expo Out, 약 0.3초.

M9. 하드컷과 빈 모눈 (Clean Cut) — 섹션 사이

  • 페이드나 와이프 없이 컷으로 넘어간다. 새 섹션의 첫 2~9프레임은 빈 모눈 배경이고, 그 뒤 첫 요소가 들어온다.
  • 컷 지점: 2.6, 6.2, 10.3, 13.1, 17.0초

6. 우리 파이프라인(Python)에 적용하는 방법

지금까지 만든 스크립트(make_video_vox_v2.py 등)에 바로 붙일 수 있는 형태로 정리했습니다.

import math
from PIL import Image, ImageDraw, ImageFilter

FPS, STEP_FPS = 30, 12

def step_time(t):                      # (1) 12fps 스텝: 모든 애니메이션의 t를 이 값으로 대체
    return math.floor(t * STEP_FPS) / STEP_FPS

def expo_out(x):                       # (2) M1·M4·M5: 빠르게 들어오고 길게 감속
    x = min(max(x, 0), 1)
    return 1 if x == 1 else 1 - 2 ** (-10 * x)

def snap(x):                           # M6: 거의 선형으로 가다가 끝에서 급정지
    x = min(max(x, 0), 1)
    return x if x < 0.85 else 0.85 + 0.15 * (1 - (1 - (x - 0.85) / 0.15) ** 3)

def defocus(sprite, p, max_r=8):       # (3) 등장 흐림 → 선명 (p: 0~1 진행도)
    r = max_r * (1 - p)
    return sprite.filter(ImageFilter.GaussianBlur(r)) if r > 0.3 else sprite

def motion_blur(render_at, t, shutter=1/24, n=6):
    """(3) 빠른 이동 모션 블러: 셔터 시간 동안 n장을 렌더해 평균 (render_at(t) -> RGB Image)."""
    frames = [render_at(t - shutter * i / n) for i in range(n)]
    acc = frames[0]
    for i, f in enumerate(frames[1:], 2):
        acc = Image.blend(acc, f, 1 / i)
    return acc

def words_visible(text, t, start, per_word=0.2):   # M2: 단어 단위 타이핑
    words = text.split()
    k = max(0, min(len(words), int((t - start) / per_word) + 1))
    return " ".join(words[:k])

def draw_hand_ellipse(draw, box, p, color=(220, 30, 30), width=6, overshoot=0.15):
    """M3: 손그림 타원 그리기. p=0~1 진행도, 끝점이 시작점을 지나쳐 튀어나오게 그린다."""
    x0, y0, x1, y1 = box
    cx, cy, rx, ry = (x0 + x1) / 2, (y0 + y1) / 2, (x1 - x0) / 2, (y1 - y0) / 2
    total = 2 * math.pi * (1 + overshoot)
    pts = []
    for i in range(int(120 * p) + 1):
        a = -2.6 + total * (i / 120)
        wob = 1 + 0.04 * math.sin(a * 3)            # 손떨림
        pts.append((cx + rx * wob * math.cos(a), cy + ry * wob * math.sin(a) - 6 * (a / total)))
    if len(pts) > 1:
        draw.line(pts, fill=color, width=width, joint="curve")

적용 순서 예시 (한 섹션, 약 3.5초) 1. t=0.00 컷. 빈 배경만 보인다. 2. t=0.25 메인 사진을 Whip-In(expo_out, 0.3초, 모션 블러와 defocus) 3. t=0.55 제목을 단어 단위 타이핑(words_visible, 단어당 0.2초) 4. 제목이 끝나면 +0.15초 뒤 핵심 단어에 빨간 타원(0.5초), 이어서 화살표(0.3초) 5. t≈1.6~3.3 정지(그레인만 움직임) 6. 다음 섹션으로 하드컷, 또는 사진이 있으면 Zoom-Through(M5)로 연결 7. 전체 렌더링 시 step_time()으로 12fps 스텝을 적용

7. 우리 영상(자동차 변천사)에 적용할 때의 제안

현재 방식 샘플 스타일에 맞춘 대안
연도 숫자 카운트업 유지하되 12fps 스텝과 흐림에서 선명으로 등장을 추가
제목 형광펜 스와이프 빨간 손그림 타원이나 밑줄로 교체(M3). 또는 형광펜은 유지하고 화살표를 추가
요소 슬라이드 인·아웃 Whip-In(모션 블러와 Expo Out)으로 등장시키고, 퇴장 애니메이션 없이 하드컷
장면 전환(종이 와이프 등) 사진이 이어지는 구간은 Zoom-Through 매치컷(M5). 예: 1908 모델 T 사진으로 줌인한 뒤 1950년대 사진에서 줌아웃
엔딩 마지막 문구에 빨간 타원을 그린 뒤 스냅 줌 푸시인(M6)하고 2초 정지
