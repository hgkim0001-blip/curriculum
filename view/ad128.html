일러스트레이터–Claude MCP 연결 가이드

2026-10-05 · 김사부

개요

일러스트레이터는 Claude Desktop의 설정 파일에 로컬 MCP 서버 한 항목을 추가하면 연결됩니다. 연결 후에는 대화로 문서 읽기, 도형·텍스트 생성, 레이어 정리, 내보내기, 저장을 지시할 수 있습니다.

사용한 서버는 illustrator-mcp-server(제작 ie3jp, MIT 라이선스)입니다. 포토샵·에펙·프리미어 MCP와 같은 방식으로 동작합니다.

명령이 전달되는 순서는 다음과 같습니다.

  1. Claude Desktop이 MCP 프로토콜로 서버(Node.js)에 도구 호출을 보냅니다.
  2. 서버가 ExtendScript(JSX) 스크립트를 만들어 PowerShell COM으로 일러스트레이터에 전달합니다.
  3. 일러스트레이터가 스크립트를 실행하고 결과를 JSON으로 돌려줍니다.

Adobe 공식 커넥터(Adobe for Creativity)는 클라우드 방식이라 PC에 설치된 일러스트레이터를 직접 조작하는 용도로는 맞지 않습니다.

준비물

항목 요구 사항 이번 작업 환경
Claude Desktop 로컬 MCP 서버를 실행할 수 있는 데스크톱 앱 Windows 노트북
Node.js 20 이상 (node -v로 확인) 설치됨
Adobe Illustrator 2024(v28) 이상 검증, 2020~2023은 미검증 Illustrator 2024
운영체제 macOS, Windows Windows

제작자는 Windows를 실제 기기에서 테스트하지 않았다고 밝히고 있지만, 이번 작업에서는 읽기·생성·레이어 이동·내보내기·저장이 모두 동작했습니다.

설정 파일 수정

수정할 파일은 C:\Users\<사용자명>\AppData\Roaming\Claude\claude_desktop_config.json입니다. Claude Desktop의 설정 > 개발자 > 구성 편집으로도 열 수 있습니다.

mcpServers 안에 아래 illustrator 항목을 추가합니다. 앞 항목의 닫는 중괄호 뒤에 쉼표를 붙여야 합니다.

"illustrator": {
  "command": "npx",
  "args": [
    "-y",
    "illustrator-mcp-server"
  ]
}

기존 서버(AfterEffectsMCP, premiere-pro-v2, cinema4d, photoshop)와 preferences 등 나머지 내용은 그대로 둡니다.

설정 파일 대신 확장 파일로 설치할 수도 있습니다. GitHub Releases에서 illustrator-mcp-server.mcpb를 받아 설정 > 확장 프로그램에 끌어다 놓으면 됩니다. 이 방식은 자동 업데이트가 되지 않습니다.

적용과 연결 확인

  1. 기존 claude_desktop_config.json을 복사해 백업합니다.
  2. 수정한 내용을 저장합니다.
  3. Claude Desktop을 트레이 아이콘에서 완전히 종료한 뒤 다시 실행합니다.
  4. 설정 > 개발자에서 illustrator 서버가 실행 중으로 표시되는지 확인합니다.
  5. 일러스트레이터를 실행하고 문서를 하나 엽니다.
  6. Claude에게 "현재 문서 정보 알려줘"라고 요청합니다. 문서 크기, 색상 모드, 아트보드 수가 돌아오면 연결된 것입니다.

할 수 있는 작업

서버는 60개가 넘는 도구를 제공하며, 이번에 실제로 써 본 요청은 아래와 같습니다.

요청 결과
"illustrator라는 글씨를 써봐" 아트보드 중앙에 200pt 텍스트 생성
"필기체로 바꾸고 150% 키워줘, 가운데 정렬" Brush Script MT 300pt로 변경 후 중앙 배치
"드롭쉐도우를 적용해줘" 문서에 있던 Drop Shadow 그래픽 스타일 적용
"강아지 캐릭터를 만들어줘" 타원 17개로 플랫 카툰풍 강아지 생성
"리깅용 여자 캐릭터도 만들어줘" 부위별 레이어 21개로 된 정면 캐릭터 생성
"화면의 캐릭터를 리깅용으로 수정해줘" 한 그룹이던 캐릭터를 부위별 레이어로 분리
"이 캐릭터를 저장해줘" 지정 폴더에 .ai 파일로 저장

작업 결과는 PNG로 내보내 Claude가 직접 눈으로 확인할 수 있습니다. 수정 전후 비교에 유용합니다.

리깅용 캐릭터 레이어 분리

커피를 든 여성 캐릭터는 전체가 이름 없는 그룹 하나였고, 이를 겉모습 변화 없이 최상위 레이어 24개로 나눠 D:\illustratormcp\캐릭터 소스\woman_coffee_rig.ai로 저장했습니다. 에펙에서 "컴포지션 - 레이어 크기 유지"로 가져오면 부위별 레이어로 들어옵니다.

부위 레이어
얼굴 Mouth, Eye_L, Eye_R, Hair_Front, Cheek_L, Cheek_R, Head, Ear_L, Ear_R
머리 뒤 Hair_Back
몸통 Cardigan, Torso, Neck
팔 Arm_R_Upper, Arm_R_Lower, Hand_R, Arm_L_Upper, Arm_L_Lower, Hand_L
다리 Leg_L, Leg_R, Foot_L, Foot_R
소품 Coffee

L/R은 캐릭터 본인 기준이라 화면 왼쪽이 _R입니다. 에펙에서는 얼굴 부위와 Hair_Back을 Head에, Head를 Neck에, Neck을 Torso에 부모로 연결합니다.

아직 남은 작업은 일러스트레이터에서 직접 해야 합니다.

  • [ ] 다리를 무릎 위치에서 잘라 Upper/Lower로 분리
  • [ ] 어깨와 팔꿈치에 둥근 겹침 추가
  • [ ] 굽혀진 팔을 편 중립 포즈로 수정
  • [ ] 립싱크용 입 모양과 눈썹 추가

한계와 문제 해결

이 서버는 도형·텍스트·레이어 단위 작업에 강하고, 패스를 자르거나 합치는 작업과 효과 세부 조정은 하지 못합니다.

상황 원인과 대처
패스 자르기, 패스파인더가 필요함 해당 도구가 없음. 일러스트레이터에서 직접 작업
드롭 섀도 값을 바꾸고 싶음 그래픽 스타일 적용만 가능. 모양 패널에서 직접 수정
호출이 응답 없이 4분 뒤 실패 Claude Desktop의 승인 대기 창이나 일러스트레이터의 열린 대화상자를 확인. 계속되면 Claude Desktop 재시작
엉뚱한 문서가 수정되거나 내보내짐 서버는 항상 활성 문서에 작업함. 작업 중에는 문서 탭을 바꾸지 않기
레이어로 이동이 실패 대상 레이어가 없으면 이동이 거부됨. 레이어를 먼저 만들고 이동
npx를 찾지 못함 Node.js 20 이상 설치 여부 확인. 버전 관리 도구로 설치했다면 npx 전체 경로를 command에 입력

AI가 만든 결과는 틀릴 수 있으므로, 수업 자료나 납품용 파일은 사람이 마지막에 직접 확인해야 합니다.
