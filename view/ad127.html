포토샵과 Claude 연결 가이드 (MCP)

2026-10-05 · 김사부

개요

Claude 데스크톱 앱에 @alisaitteke/photoshop-mcp 서버를 등록해 포토샵을 대화로 직접 제어하도록 연결했다. 포토샵에 플러그인이나 확장 패널을 설치하지 않고, 설정 파일에 항목 하나를 추가하는 것으로 끝난다.

항목 내용
운영체제 Windows
포토샵 버전 Photoshop 2024
Claude 데스크톱 앱 (웹 브라우저 버전은 로컬 MCP 사용 불가)
MCP 서버 @alisaitteke/photoshop-mcp (비공식, MIT 라이선스)
필요 프로그램 Node.js
연결 결과 ping 성공, 버전 정상 인식

연결 방법 비교

포토샵과 Claude를 잇는 길은 세 가지이고, 이 문서는 설치가 가장 간단한 세 번째 방식을 다룬다.

방식 대표 도구 설치 부담 특징
공식 커넥터 Claude 커넥터 디렉터리의 Adobe 커넥터 없음 (Adobe 계정 로그인) 클라우드에서 Adobe 편집 기능을 호출. 내 PC에 열린 포토샵을 직접 조작하지는 않음
UXP 플러그인 adb-mcp (Mike Chambers) 높음 (Python, Node.js, 프록시 서버, UXP Developer Tool) 포토샵 안에 플러그인을 로드해 연결. 프리미어 등 다른 앱도 함께 지원
외부 스크립트 @alisaitteke/photoshop-mcp 낮음 (설정 파일 등록만) OS 자동화 기능으로 ExtendScript를 직접 실행. 이번에 선택한 방식

같은 외부 스크립트 계열로 Windows 전용인 airtaxi/PhotoshopMcpServer(COM 기반, 도구 13개)와 loonghao/photoshop-python-api-mcp-server(Python 기반)도 있다.

설치 절차

설정 파일에 서버 항목을 추가하고 Claude를 재시작하면 끝난다.

  1. Node.js 확인. 명령 프롬프트에서 node -v를 입력해 버전 번호가 나오는지 본다. 나오지 않으면 nodejs.org에서 LTS 버전을 설치한다.
  2. 기존 설정 파일 백업. %APPDATA%\Claude\claude_desktop_config.json을 claude_desktop_config_backup.json으로 복사해 둔다.
  3. 설정 파일 열기. Claude 데스크톱 앱에서 Settings → Developer → Edit Config를 누른다. 탐색기 주소창에 %APPDATA%\Claude를 입력해 직접 열어도 된다.
  4. photoshop 항목 추가. mcpServers 안의 마지막 서버 블록 뒤에 쉼표를 붙이고 아래 "설정 파일 예시"의 내용을 넣는다. 기존 서버와 다른 설정은 건드리지 않는다.
  5. 저장 후 완전 종료. 창의 X만 누르면 백그라운드에 남는다. 작업 표시줄 트레이의 Claude 아이콘을 우클릭해 Quit을 누른다.
  6. 재실행. Claude를 다시 켠다. 처음에는 npx가 패키지를 내려받느라 1분 정도 걸릴 수 있다.
  7. 상태 확인. Settings → Developer의 서버 목록에서 photoshop이 running인지 본다.

설정 파일 예시

claude_desktop_config.json의 mcpServers 안에 아래 photoshop 블록을 추가한다. 앞 블록 끝의 쉼표가 빠지면 파일 전체가 읽히지 않는다.

{
  "mcpServers": {
    "cinema4d": {
      "command": "python",
      "args": ["D:\\mcp\\cinema4d-mcp\\cinema4d-mcp-main\\main.py"]
    },
    "photoshop": {
      "command": "npx",
      "args": ["-y", "@alisaitteke/photoshop-mcp"],
      "env": {
        "LOG_LEVEL": "1",
        "ANALYTICS_DISABLED": "1"
      }
    }
  }
}
설정값 의미
command, args npx로 패키지를 내려받아 실행. -y는 설치 확인 질문을 건너뜀
LOG_LEVEL 로그 수준. 0=DEBUG, 1=INFO, 2=WARN, 3=ERROR
ANALYTICS_DISABLED 1로 두면 익명 사용 통계 수집을 끔. 기본값은 수집
PHOTOSHOP_PATH (선택) 포토샵을 자동으로 찾지 못할 때 설치 경로를 직접 지정

연결 확인

포토샵을 먼저 실행한 뒤, Claude 데스크톱 앱의 새 대화에서 아래 명령을 차례로 입력한다. 도구 사용 허용 창이 뜨면 허용한다.

  1. 연결 점검

포토샵에 ping 보내고 버전을 알려줘.

"Successfully connected to Photoshop"과 버전이 돌아오면 정상이다. 이번 환경에서는 Photoshop 2024로 인식됐다.

  1. 실제 조작 테스트

1920x1080 RGB 문서를 만들고, 가운데에 "TEST"를 72pt 흰색으로 넣어줘.

포토샵에 새 문서와 글자가 생기면 연결이 끝난 것이다.

ping은 포토샵을 대신 실행해 주지 않으므로, 포토샵이 꺼져 있으면 실패한다.

문제 해결

대부분의 문제는 JSON 문법 오류이거나 Claude를 완전히 종료하지 않은 경우다.

증상 원인 조치
서버 목록에 photoshop이 없음 쉼표나 중괄호 누락으로 설정 파일을 읽지 못함 문법을 확인하고, 안 되면 백업 파일로 되돌린 뒤 다시 추가
설정을 바꿨는데 반영되지 않음 Claude가 트레이에 남아 있음 트레이 아이콘 우클릭 → Quit 후 재실행
서버 상태가 failed Node.js 미설치 또는 npx 실행 실패 node -v로 확인. Settings → Developer의 로그 확인
ping 실패 포토샵이 꺼져 있음 포토샵을 먼저 실행
포토샵을 찾지 못함 자동 감지 실패 env에 PHOTOSHOP_PATH로 설치 경로 지정
extendscript_timeout 이전 스크립트가 아직 실행 중이거나 포토샵에 대화상자가 떠 있음 대화상자를 닫고 ping을 다시 보냄
생성형 채우기 등이 동작하지 않음 Firefly 기능은 Adobe 계정과 크레딧 필요 로그인 상태와 크레딧 확인

에펙·프리미어 MCP와의 차이

에펙과 프리미어는 창 > 확장의 패널을 열어둬야 하지만, 포토샵은 패널 없이 포토샵만 켜두면 된다. 자동화 통로가 다르기 때문이다.

구분 패널 방식 (에펙·프리미어) 외부 스크립트 방식 (포토샵)
통신 경로 Claude ↔ MCP 서버 ↔ CEP 패널 ↔ 앱 Claude ↔ MCP 서버 ↔ COM 자동화 ↔ 포토샵
설치 확장 패널 설치 필요 설정 파일 등록만
사용 전 준비 매번 패널을 열어야 함 포토샵만 켜두면 됨
지원 범위 패널이 구현한 기능 ExtendScript로 되는 기능 전부
한계 패널이 닫히면 연결이 끊김 UXP 전용 최신 기능은 접근 불가

macOS에서는 COM 대신 AppleScript가 같은 역할을 한다. 뉴럴 필터는 ExtendScript로 호출할 수 없어서, 선택 사항인 UXP 브리지 플러그인을 따로 설치해야 쓸 수 있다.

사용 팁과 주의사항

여러 단계가 필요한 작업은 "레시피"로 요청하면 안정적이고, 실행 취소 한 번으로 전체가 되돌려진다.

  • 레시피 종류. 배경 제거, 인물 보정, 닷지·번, 주파수 분리, 컬러 그레이딩, 웹용 내보내기, SNS 규격별 내보내기, 캐러셀 분할, 일괄 워터마크, 목업 일괄 교체, 레이어 정리 등.
  • 요청 예시. "활성 레이어의 배경을 레시피로 제거해줘", "warm_film 프리셋으로 컬러 그레이드를 조정 레이어로 적용해줘".
  • 결과 확인. 큰 작업 뒤에는 "미리보기 보여줘"라고 하면 Claude가 결과 이미지를 받아 직접 확인한다.
  • 백업. 비공식 도구이므로 중요한 PSD는 사본으로 먼저 테스트한다.
  • 설정 파일 관리. Claude 앱이 이 파일에 다른 설정도 함께 저장하므로, 통째로 덮어쓰기보다 photoshop 블록만 추가하는 편이 안전하다.
  • 업데이트. npx -y는 실행할 때 패키지를 받아오고, 이 서버는 업데이트가 잦다. 수업 직전에 동작을 한 번 확인해 둔다.
